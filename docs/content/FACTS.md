# Единый набор фактов для «Код доступа: Эпохи»

Этот файл — нормативный источник содержания для экранов, заданий и пояснений проекта. Если старые методические материалы расходятся с ним, используется формулировка отсюда.

## Египет

- Система десятичная и непозиционная.
- Отдельные иероглифы обозначают 1, 10, 100, 1 000 и следующие степени десяти. Знак повторяют нужное число раз, а значения складывают.
- Порядок знаков не задаёт разрядный вес, поэтому перестановка знаков не меняет сумму. Для учебных ответов используется порядок от большего значения к меньшему.
- Самостоятельного позиционного нуля в этой записи нет.

Учебные знаки: `𓏺 = 1`, `𓎆 = 10`, `𓍢 = 100`.

## Вавилон

- Система позиционная, с основанием 60.
- Один разряд содержит значение от 0 до 59; справа находятся единицы, левее — группы по 60, затем по 3 600.
- Для учебной текстовой записи разряды разделяются запятой: `2,5 = 2 × 60 + 5 = 125`.
- В ранних записях полноценного нуля не было; позднее появился знак-заполнитель для пустого внутреннего разряда. Это не было современным нулём во всех его функциях.
- Деление времени на 60 минут и минуты на 60 секунд связано с наследием шестидесятеричной традиции.

## Рим

- Основные знаки: `I=1`, `V=5`, `X=10`, `L=50`, `C=100`, `D=500`, `M=1000`.
- В проекте используется современная каноническая запись. Разрешены только пары вычитания `IV`, `IX`, `XL`, `XC`, `CD`, `CM`; формула «любой меньший знак перед большим вычитается» неверна.
- Традиционная, а не археологически доказанная точная дата основания Рима — 753 год до н. э. Число 753 записывается `DCCLIII`.

## Древняя Русь

- Кириллическая буквенная цифирь — десятичная непозиционная система, восходящая к греко-византийской традиции.
- Буквы обозначают единицы, десятки и сотни. Над числовой записью ставили титло; в текстовых заданиях оно передаётся как помета `[под титлом]`.
- Используемые в заданиях значения: `А=1`, `В=2`, `Г=3`, `И=8`, `І=10`, `К=20`, `П=80`, `Ц=900`.
- Обычно буквы записываются от большего значения к меньшему. В числах 11–19 единица традиционно ставится перед десятком; этот особый случай не используется для автоматической проверки первой версии.
- Традиционная дата Крещения Руси — 988 год; в принятом учебном наборе букв это `ЦПИ` под титлом (`900 + 80 + 8`).

## Двоичная запись и разрядность

- `753₁₀ = 1011110001₂`.
- `3600₁₀ = 111000010000₂`; запись занимает 12 бит без ведущих нулей.
- Один беззнаковый 8-битный разряд хранит целое число от 0 до 255. Число 3600 туда не помещается.
- Intel 4004 был 4-битным процессором. Его разрядность не следует называть «4-битным байтом».
- Основание системы меняет форму и длину записи, но не меняет само значение числа и автоматически не меняет формат IP-адреса. Например, `255₁₀ = 11111111₂ = CF₂₀`, если для цифр 10–19 приняты `A–J` (`C=12`, `F=15`).

## Проверочные вычисления

- Делители 60: `1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60` — 12 делителей.
- Делители 100: `1, 2, 4, 5, 10, 20, 25, 50, 100` — 9 делителей.
- 60 удобно для многих обычных дробей, потому что делится без остатка на 2, 3, 4, 5 и 6. Это учебное объяснение свойства числа, а не доказанная единственная историческая причина выбора основания.
