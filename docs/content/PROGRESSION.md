# Правила прохождения «Код доступа: Эпохи»

## Маршрут

Игра состоит из пяти этапов и проходится только по порядку. Следующий этап открывается после выполнения всех обязательных заданий текущего этапа и сохранения его артефакта.

| Этап | Обязательные задания | Артефакт |
| --- | --- | --- |
| 1. Взлом протокола | `rome-02`, `final-01` | «Гипотеза исследователя» |
| 2. Архив НИИ Времени | `egypt-01`, `babylon-01`, `rome-01`, `rus-01` | «Паспорт числа» с четырьмя заполненными эпохами |
| 3. Компиляция | `cross-01`, `cross-02`, `cross-03` | Таблица переводов с отметкой «Проверено» |
| 4. Сборка ядра | `cross-04`, `practical-01` | Карточка совместимости |
| 5. Финальный блиц | `final-02`, `final-03` и блиц-тест из 5 вопросов за 90 секунд | «Патч для ядра» и итоговая карточка |

Остальные задания банка дополнительные: они доступны после соответствующей эпохи, дают баллы и достижения, но не блокируют маршрут.

## Баллы

- В финальном блиц-тесте за каждый правильный ответ начисляется 1 балл, максимум — 5 баллов.
- Дополнительные задания дают ещё до 25 баллов: пять лучших результатов по 5 баллов. Итог ограничен 100 баллами.
- Правильный ответ с первой попытки даёт полную стоимость задания. Вторая попытка уменьшает награду на 1 балл, третья и последующие — на 2 балла. Открытая подсказка уменьшает награду ещё на 1 балл. За выполненное задание всегда начисляется не меньше 1 балла.
- Для практического кейса штрафы удваиваются: 2 балла за вторую попытку, 4 за третью и последующие, 2 за подсказку; минимум — 2 балла.
- Ответ засчитывается только после явной проверки. Пустой ответ попыткой не считается.

## Попытки и обратная связь

- Число попыток не ограничено: ученик не может навсегда заблокировать маршрут.
- После первой ошибки показывается короткая подсказка из поля `hint`.
- После второй ошибки показывается `errorExplanation`, но правильный ответ автоматически не подставляется.
- После третьей ошибки открывается разобранный пример того же типа; затем ученик снова отвечает на исходное задание.
- При повторном входе сохраняются введённые ответы, число попыток, открытые подсказки, баллы и артефакты.
- Повтор уже выполненного задания разрешён для тренировки, но баллы за него повторно не начисляются. Полный сброс прогресса требует отдельного подтверждения.

## Успешное завершение

Игра завершена успешно, только если одновременно выполнены четыре условия:

1. Засчитаны все 13 обязательных заданий.
2. Сохранены все пять артефактов.
3. Завершён блиц-тест из пяти вопросов за 90 секунд.
4. Набрано не менее 60 из 100 баллов.

Если обязательные задания выполнены, но баллов меньше 60, открывается режим восстановления: для каждого обязательного задания, решённого со штрафом, можно один раз выполнить равноценный вариант и вернуть до 2 потерянных баллов (для практического кейса — до 4). Также можно выполнить дополнительные задания. Уже полученные артефакты сохраняются; общий итог по-прежнему ограничен 100 баллами.

## Достижения

| Достижение | Условие |
| --- | --- |
| «Архивист эпох» | Засчитано хотя бы по одному заданию каждой из четырёх цивилизаций |
| «Безошибочный дешифровщик» | Все обязательные задания этапов 2–3 решены с первой попытки без подсказок |
| «Мастер шестидесяти» | Засчитаны `babylon-03` и `cross-02` |
| «Хранитель разрядов» | Засчитаны `cross-01` и `cross-04` |
| «Полный допуск» | Выполнены условия успешного завершения и набрано не менее 90 баллов |

## Итоговый продукт ученика

Итогом считается экспортируемая карточка «Патч для ядра». Она содержит имя или код команды, четыре строки «цивилизация — система — пример записи — историческое объяснение», перевод 753 в римскую и двоичную запись, вывод о числе 3600 и диапазоне 8 бит, гипотезу первого этапа, ответы финальной защиты, список достижений и итоговый балл. Без всех этих полей продукт считается черновиком.
