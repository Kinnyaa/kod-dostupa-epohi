# 02. Архитектура приложения

## ARCH-01 — разделить страницу на экраны — P0

- Создать представления пяти этапов и итогового экрана.
- Выделить шапку, шкалу прогресса, таймер, карточку задания и панель артефактов.
- Отделить данные заданий от отрисовки.
- Установить русскую локаль документа и семантическую разметку.

## ARCH-02 — реализовать состояние — P0

- Хранить текущий этап, ответы, попытки, баллы, артефакты и время.
- Сохранять и восстанавливать данные через `localStorage`.
- Добавить сброс прогресса с подтверждением.

## ARCH-03 — реализовать навигацию — P0

- Добавить действия «назад» и «дальше».
- Блокировать недоступные этапы.
- Синхронизировать верхнюю шкалу и правую панель.

## Предлагаемая структура `src`

```text
src/
├── data/              # задания, цивилизации, достижения
├── js/
│   ├── components/    # повторяемые элементы интерфейса
│   ├── screens/       # экраны этапов
│   ├── services/      # storage и таймер
│   ├── utils/         # конвертеры и валидаторы
│   └── main.js
├── scss/
│   ├── components/
│   ├── screens/
│   └── main.scss
└── img/
```

Готово, когда этапы отрисовываются из состояния, а перезагрузка не сбрасывает прохождение.
