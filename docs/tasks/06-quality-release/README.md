# 06. Качество и выпуск

## QA-01 — автоматические проверки — P1

- Тесты преобразования римских и двоичных чисел.
- Тесты валидаторов, прогресса и сохранения состояния.
- Smoke-тест прохождения пяти этапов.

## QA-02 — ручная приёмка — P0

- Проверить Chrome, Edge и мобильные размеры.
- Пройти правильные и ошибочные сценарии.
- Проверить клавиатуру, таймер, перезагрузку и сброс.
- Сверить факты и ключи с утверждённым банком.

## RELEASE-01 — сборка и публикация — P1

- Обновить основной README.
- Выполнить production-сборку.
- Проверить пути к изображениям и шрифтам.
- Опубликовать на статической площадке и проверить в инкогнито.

Релиз готов, когда опубликованная версия работает без локальных зависимостей и ошибок консоли.
