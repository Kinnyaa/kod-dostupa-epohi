# 01. Содержание

## CONTENT-01 — устранить противоречия — P0

**Статус: выполнено.** Нормативный набор формулировок: [`../../content/FACTS.md`](../../content/FACTS.md).

- Египет описывать как десятичную непозиционную систему, а не 12-ричную.
- Не называть разрядность Intel 4004 размером байта.
- Заменить некорректный пример с «20-ричным IP» на сравнение ёмкости разряда или длины записи.
- Проверить римские числа, исторические даты и правила славянской цифири.
- Использовать единое название «Код доступа: Эпохи».

Готово, когда утверждён один набор фактов для всех экранов.

## CONTENT-02 — создать банк заданий — P0

**Статус: выполнено.** Единый объект данных: [`../../content/question-bank.json`](../../content/question-bank.json).

- Подготовить по 2–3 задания на каждую цивилизацию.
- Добавить задания на римскую и двоичную запись, делители 60 и сравнение систем.
- Для задания хранить условие, правильный ответ, допустимые варианты, подсказку и объяснение ошибки.
- Подготовить три финальных вопроса и практический кейс.

Готово, когда задания можно хранить единым объектом данных отдельно от интерфейса.

## CONTENT-03 — определить правила прохождения — P1

**Статус: выполнено.** Баллы, попытки, артефакты и условия завершения: [`../../content/PROGRESSION.md`](../../content/PROGRESSION.md).

- Отметить обязательные задания.
- Определить баллы, артефакты и достижения.
- Установить условия успешного завершения и повторной попытки.
- Зафиксировать итоговый продукт ученика.

Готово, когда сценарий от старта до результата не допускает неоднозначностей.
