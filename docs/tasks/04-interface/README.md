# 04. Интерфейс

## UI-01 — завершить базовый макет — P0

- Стилизовать правую панель, таймер, прогресс, артефакты и достижение.
- Подключить изображения карточек.
- Удалить пустые блоки и мёртвую закомментированную разметку.
- Собрать сетку и унифицировать визуальные компоненты.
- Проверить ширины 1440, 1024, 768 и 375 px.

## UI-02 — добавить состояния — P0

- Правильный/неправильный ответ.
- `focus`, `hover`, `disabled`, `loading`.
- Подсказка, артефакты и состояния этапов.

## UI-03 — обеспечить доступность — P1

- Клавиатурная навигация и видимый фокус.
- `label`, `aria-live`, контраст и альтернативные тексты.
- Поддержка `prefers-reduced-motion`.
- Цвет не должен быть единственным сигналом.

Готово, когда основной сценарий понятен и проходится без мыши.
