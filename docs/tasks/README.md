## Определение готового продукта

- Пять этапов проходятся от начала до конца.
- Ответы проверяются с понятной обратной связью.
- Прогресс сохраняется после перезагрузки.
- Интерфейс работает на ширинах 375–1440 px и с клавиатуры.
- `npm run build` завершается без ошибок.
- Все исторические факты и ключи ответов выверены.

## Обозначения

- **P0** — блокирует рабочий прототип.
- **P1** — требуется для полного релиза.
- **P2** — улучшение после основной версии.
