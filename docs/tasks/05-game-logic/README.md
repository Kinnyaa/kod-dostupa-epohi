# 05. Игровая логика

## LOGIC-01 — проверка ответов — P0

- Нормализовать пробелы, регистр и допустимые формы записи.
- Создать валидаторы чисел, римской записи и открытых ответов.
- Давать объясняющую обратную связь.
- Учитывать попытки и подсказки при начислении баллов.

## LOGIC-02 — таймер — P1

- Определить работу при скрытой вкладке.
- Добавить предупреждения по времени.
- Восстанавливать отсчёт после перезагрузки.
- Не терять введённые данные после завершения времени.

## LOGIC-03 — артефакты и достижения — P1

- Связать награды с действиями и показать условия получения.
- Добавить достижение за изучение всех цивилизаций.
- Вычислять счётчики из состояния.
- Исправить расхождение «3 из 12» и четырёх отмеченных карточек.

Готово, когда ответы проверяются корректно, а награды и счётчики совпадают с прогрессом.
