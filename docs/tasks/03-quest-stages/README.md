# 03. Этапы квеста

## STAGE-01 — «Взлом протокола» — P0

- Правила, шифровка с ошибкой, выбор нарушения и поле гипотезы.
- Артефакт «Гипотеза исследователя».

## STAGE-02 — «Архив НИИ Времени» — P0

- Изображения и справки четырёх цивилизаций.
- Проверяемый вопрос по египетской записи.
- «Паспорт числа»: система, алфавит, число, причина появления.
- Артефакты открываются после выполненных заданий.

## STAGE-03 — «Компиляция» — P0

- Перевод 753 в римскую и двоичную запись.
- Разбор ошибки и сравнение делителей 60 и 100.
- Таблица переводов с отметками «Проверено».

## STAGE-04 — «Сборка ядра» — P1

- Двоичная запись числа и необходимое количество бит.
- Проверка диапазона 8 бит `0–255`.
- Объяснение исторического контекста и карточка совместимости.

## STAGE-05 — «Защита перед Советом» — P1

- Сводка результатов и финальные вопросы.
- 90-секундный таймер защиты.
- Итоговый результат и печатная карточка.

Каждый этап готов, когда проходится с клавиатуры, даёт обратную связь и открывает следующий.
