# Задачи проекта «Код доступа: Эпохи»

Подробный план разнесён по папке [`docs/tasks`](docs/tasks/README.md).

## Порядок работы

1. [`01-content`](docs/tasks/01-content/README.md) — выверить факты, задания и правила.
2. [`02-architecture`](docs/tasks/02-architecture/README.md) — собрать каркас экранов, состояние и навигацию.
3. [`03-quest-stages`](docs/tasks/03-quest-stages/README.md) — реализовать пять этапов квеста.
4. [`04-interface`](docs/tasks/04-interface/README.md) — завершить адаптивный интерфейс и доступность.
5. [`05-game-logic`](docs/tasks/05-game-logic/README.md) — проверка ответов, таймер и достижения.
6. [`06-quality-release`](docs/tasks/06-quality-release/README.md) — тесты, приёмка и публикация.

## Первая итерация

- CONTENT-01 — исправить противоречия в материалах.
- CONTENT-02 — подготовить банк заданий и ответов.
- ARCH-01 — разделить страницу на игровые экраны.
- ARCH-02 — реализовать состояние и `localStorage`.
- UI-01 — закончить базовый макет.
- STAGE-02 — превратить второй этап в рабочий интерактивный экран.

## Релизы

- **Релиз 1:** этапы 1–3, ответы, навигация, сохранение прогресса, адаптивный интерфейс.
- **Релиз 2:** этапы 4–5, таймер, артефакты, достижения, итоговая карточка.
- **Релиз 3:** тесты, редактура, README и публикация.
