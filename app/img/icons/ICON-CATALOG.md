# Ancient Icons

SVG-спрайт: `ancient-icons.svg`. Каждый `id` — отдельная иконка, которую можно подключить так:

```html
<svg aria-hidden="true"><use href="./icons/ancient-icons.svg#navigation-home"></use></svg>
```

## Навигация

`navigation-home`, `navigation-timeline`, `navigation-passport`, `navigation-results`, `navigation-back`, `navigation-forward`, `navigation-menu`, `navigation-close`

## Состояния

`status-locked`, `status-key`, `status-complete`, `status-current`, `status-error`, `status-hint`, `status-time`, `status-score`, `status-reward`, `status-progress`

## Исторические эпохи

`historical-egypt`, `historical-babylon`, `historical-rome`, `historical-rus`, `historical-greece`

## Задания
